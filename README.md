# JURISDICTION

### Universal Gaming & System Optimization Suite

**One control center. Every game. Your system.**

JURISDICTION is a Windows desktop optimization application designed to bring gaming configuration, graphics settings, system tools, and performance monitoring into one unified interface.

The goal is to give users more control over their gaming experience through organized settings, hardware-aware profiles, and configurable optimization tools.

---

## 🎯 Project Goals

JURISDICTION aims to make PC optimization easier, more accessible, and more organized.

Instead of switching between multiple programs and manually editing configuration files, users will eventually be able to manage supported settings from one application.

## ✨ Planned Features

### 🖥️ Hardware Detection
- Detect CPU, GPU, and installed RAM.
- Identify GPU manufacturers: NVIDIA, AMD, and Intel.
- Display system information.
- Detect monitor resolution and refresh rate.

### 🎮 Game Optimization

Planned game support:
- Roblox
- Minecraft
- Geometry Dash

Potential capabilities:
- Game-specific configuration tools.
- Custom optimization profiles.
- Import and export settings.
- JSON configuration editing and validation.

### 🎨 GPU Control Center
- NVIDIA graphics configuration.
- AMD graphics configuration.
- Intel graphics configuration.
- Supported universal graphics settings.
- Hardware and driver compatibility detection.

*Available controls will depend on the GPU and driver.*

### ⚙️ Windows Optimization
- Organized Windows configuration tools.
- Optional system performance adjustments.
- Explanations for available settings.
- Backup and restore functionality.

### 📊 Performance Monitoring
- FPS monitoring.
- Frame-time monitoring.
- Before-and-after performance comparisons.
- Benchmarking tools.

## 🚧 Development Status

**Status: Early Development**

JURISDICTION is currently in its planning and development stages.

Features, supported hardware, and capabilities are subject to change as development progresses.

## 🔒 Safety & Reliability

JURISDICTION aims to prioritize safe and transparent configuration changes.

- Explain what settings do.
- Check hardware compatibility.
- Avoid applying unsupported settings.
- Provide backup and restore options where possible.
